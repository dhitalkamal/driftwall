Driftwall

Your desktop, in motion.

Free and open-source live video wallpaper for macOS. It sits behind your icons, loops seamlessly across every display, and stays light on battery.

Download View on GitHub

Behind your icons

Renders at the desktop layer so you keep clicking, dragging, and working as usual.

Every display

A single video everywhere, or a different one per screen, following monitors as you plug and unplug them.

Playlists

Rotate through a set of videos on a schedule, with optional shuffle.

Battery aware

Pauses on a fullscreen app or on battery, so it does not drain your Mac.

Your videos

Point it at any .mp4 or .mov. Nothing is uploaded; everything stays on your Mac.

Open source

MIT licensed. Read the code, file issues, and send pull requests on GitHub.

Build it yourself

macOS 13+ and the Xcode command line tools. Clone the repo and run: 

git clone https://github.com/dhitalkamal/driftwall.git
cd driftwall
scripts/install.sh
